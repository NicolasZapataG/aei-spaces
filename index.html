⚙ Conectar a SharePoint
Sigue estos pasos una sola vez con tu administrador M365. Cuando tengas los datos, pégalos aquí y el dashboard se conecta al Excel maestro.
Paso 1 — Azure AD (pide a IT)
1. Ir a portal.azure.com → Azure Active Directory → App Registrations → New
2. Nombre: AEI Dashboard · Tipo: Single-page application
3. Redirect URI: la URL donde quedes el dashboard (o http://localhost para pruebas)
4. Copiar Application (client) ID y Directory (tenant) ID
5. API Permissions → Add → Microsoft Graph → Files.Read, Sites.Read.All, Sites.ReadWrite.All
Paso 2 — SharePoint List (tú mismo)
1. Ir a tu sitio SharePoint → Site Contents → New List
2. Nombre: AEI_Overrides
3. Agregar columnas: item_id (número), complejidad (texto), estado_manual (texto)
Paso 3 — Pega tus datos aquí
Client ID de Azure AD
Tenant ID de Azure AD
URL del sitio SharePoint
ID del archivo Excel (desde Graph Explorer)
